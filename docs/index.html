25 Ops: A UOp Compiler from Scratch

How it was built

Part 1: Week 1: UOps, Rewrites and the Renderer

The hash-consed UOp graph, dtype/shape/bounds inference, the .uir text format, an exact evaluator, a bottom-up rewrite engine with constant folding and symbolic simplification, function calls, and a C renderer. Milestone: threefry2x32-20 written with arithmetic only, checked against the reference vectors.

Part 2: Week 2: Memory and Shape

Buffers, call-scoped storage, loads, stores and AFTER: a program now has effects. Verify that every access is in bounds and every load and store is ordered, emit C statements for memory ops, and render and call loopless kernels on numpy arrays.

Part 3: Week 3: Loops

RANGE and END: loops in the graph. Check that loop values never escape their loop, schedule nodes into nested loops with loop-invariant code hoisted out, compile and run looping kernels, and write a GEMM.

Part 4: Week 4: Rangeify, Fusion and Materialization

Shaped programs: REDUCE, EXPAND and STAGE on vectors. Lower any shaped value to the scalar computing one element at an index, materialize reductions and staged values into temporary buffers, and run whole shaped programs end to end.

Part 5: Week 5: Movement Ops

RESHAPE and PERMUTE on any rank: matmul and transposes from movement ops alone, PAD and FLIP built as composites, and Keccak-f[1600] in under 99 UOps, checked against SHA3-256.

Part 6: Week 6: Autodiff and MNIST

GRADIENT and DETACH: reverse-mode autodiff as a graph rewrite before rangeify, buffers fetched by url and checked by sha256, and an MNIST trainer whose initialization (threefry), forward pass, backward pass, SGD loop and test accuracy are all one compiled .uir program.
